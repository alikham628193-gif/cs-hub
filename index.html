DATA SETTINGS

CS2 DATA API

Не подключён

Ключ API хранится безопасно в настройках хостинга Netlify, а не в браузере посетителя.

После загрузки сайта открой Netlify → Site configuration → Environment variables и добавь переменную CITO_API_KEY со своим ключом. Затем нажми Deploys → Trigger deploy.

Документация ↗
Не вставляй секретный ключ в сам HTML и не отправляй его в чат. Бесплатный план может иметь лимиты, а данные могут обновляться с задержкой.
